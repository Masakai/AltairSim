# altairclone.com のダウンロード一覧

- 取得先のライセンスや利用条件は、各自で確認してください。このリポジトリには、これらのファイルを含めていません(取り込み方は [library.md](library.md))
- 「使用」欄の ○ は、このシミュレータが使うファイルと同じ名前のもの(`AssetLibrary.catalog`)です。名前が同じだけで、内容の同一性は確かめていません
- URL は `https://altairclone.com/downloads/` からの相対パスで書いています
- 一覧の更新日は、サイトの表示のままです
